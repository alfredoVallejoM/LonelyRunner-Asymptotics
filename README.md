Empirical Asymptotics of the Lonely Runner Conjecture (k=2000)

This repository contains the source code, high-performance computing (HPC) engines, and plotting scripts associated with the paper: "Empirical Asymptotics of the Lonely Runner Conjecture: Diophantine Incompressibility and Euler's Totient Function up to k=2000".

By shifting the paradigm from point-existence to global Lebesgue measure evaluation over the unit torus T1, this project maps the topological density of the loneliness set across seven distinct Diophantine regimes, leading to the formulation of the Spectral Gap Conjecture.
Repository Structure

    lone_runner_hpc_engine.py: The core computation engine. It features a dual-architecture:

        Exact Rational Sweep-Line Engine: Evaluates polynomial and harmonic regimes using strict arbitrary-precision integer fractions (cross-multiplication) to prevent IEEE 754 floating-point blindness.

        Big-Int Ergodic Integrator: Handles exponential regimes (Fibonacci, Lacunary) via high-resolution discrete Monte Carlo sampling over 10150 minimal units.

    generate_plots.py: The visualization script that parses the dataset and generates the high-fidelity vector graphics (PDF) used in the paper.

    unified_lonely_runner_topology.csv: The complete dataset of 13,995 exact measure integrations. (Note: The master copy is permanently hosted on Zenodo).

Prerequisites and Installation

The scripts are written in Python but are designed to be fully compatible with the SageMath algebraic ecosystem, which is highly recommended for researchers wishing to extend the Galois orbit and cyclotomic polynomial analysis discussed in the paper.
Option A: Standard Python Installation

You will need Python 3.11 or higher. The core engine only uses standard libraries, but the plotting script requires pandas and matplotlib.

Clone the repository:
git clone https://github.com/alfredoVallejoM/LonelyRunner-Asymptotics.git
cd LonelyRunner-Asymptotics

Create a virtual environment and install dependencies:
python3 -m venv venv
source venv/bin/activate
pip install pandas matplotlib numpy
Option B: SageMath Installation (Recommended for Algebraic Extensions)

SageMath includes all necessary Python libraries along with advanced number theory modules.

    Download and install SageMath from the official website or via Conda/Mamba:
    mamba create -n sage -c conda-forge sage python=3.11
    mamba activate sage

    Install the plotting dependencies within the Sage environment:
    sage -pip install pandas matplotlib

Usage
1. Running the HPC Engine

To run the exact topological evaluation (warning: computing up to k=2000 requires significant CPU hours):

Via Standard Python:
python lone_runner_hpc_engine.py

Via SageMath:
sage -python lone_runner_hpc_engine.py

The script is designed to safely resume from the last computed k if interrupted.
2. Generating the Paper Figures

To reproduce the exact vector graphics (Figure 1: Measure Spectrum, and Figure 2: Euler's Totient Function) from the dataset:

python generate_plots.py

This will output measure_spectrum_plot.pdf and euler_totient_plot.pdf into the working directory.
Data Availability

The complete unified dataset generated by this project is permanently archived on Zenodo. It contains the exact evaluations for k∈[2,2000] across the seven Diophantine regimes.
